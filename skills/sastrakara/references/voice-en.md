# Voice reference: English

Read this when the document language is English, or as the reader-check examples for a
language that has no reference file of its own.

## Voice

- "You" for the reader, "we" for the team.
- Explain a term the first time it appears, in everyday words. Examples:
  - API: "the channel an application uses to ask another system for data, like a service counter"
  - Cache: "a temporary copy, so the page does not have to ask for the same data again and again"
  - Frontend: "the part of the application you see and click on screen"
  - Database: "the filing cabinet where the system keeps its records"
- Analogies that work for flows: a service counter, a notice board, a filing cabinet, a courier.
- A useful small table: "Information shown · Data source · How often it is updated".

## Fixed strings

| Use | Text |
|---|---|
| Unknown, needs an answer | *(to be confirmed by the technical team)* |
| Planned work | "planned, not yet available" |
| Technical appendix heading | Technical Appendix |
| Technical appendix opener | "This section is for the technical team. Business readers can skip it." (italic) |
| Key-terms heading | Key Terms |
| Limits heading | Limits and Things to Watch |
| Index columns | Document · For whom · Date · Format · Status |
| Index status | `Draft MD` · `DOCX` · `DOCX edited by hand` |
| Date | long form, for example "1 October 2026" |
| Front matter | `lang: en-US` (or `en-GB`) |

## Reader check: what each question catches

**1. Would the reader miss it?**

| Found in the draft | Do this |
|---|---|
| "As technology keeps advancing, …" | Begin with the subject of the section |
| "Let us walk through these one by one." | Go straight to the first item |
| "This document will outline how the report works." | Describe how the report works |
| "That concludes this overview; we trust it was useful." | End on the last fact |

**2. Where did it come from?**

| Found in the draft | Do this |
|---|---|
| "Users love this feature." | Delete; no file shows it |
| "It is widely considered the safest approach." | Name the source, or delete |
| "The service will become more complete over time." | Delete, or state a real plan labelled "planned, not yet available" |

**3. Describe or decorate?**

| Found in the draft | Do this |
|---|---|
| "A powerful, innovative system" | "The system stays available when one server stops" |
| "The report is sent every morning" (the sender is known) | "The system sends the report every morning" |
| "The app knows what you are looking for" | "The app shows your last five searches" |
| "As we all know", "at the end of the day", "for the purpose of" | Delete, or keep only "to" |

**4. Is the shape earned?**

| Found in the draft | Do this |
|---|---|
| Heading "How It Works", first sentence "Here is how it works." | First sentence starts the explanation |
| "More than a table, it is a decision hub." | Say once what the table is used for |
| "fast, simple and secure" where only speed was shown | Keep what the code shows |
| Every important word in bold, emoji in headings | Bold for warnings only, no emoji |
| A paragraph that closes with "Because good data is where good decisions begin." | Stop at the last fact |
